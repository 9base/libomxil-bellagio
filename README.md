# Bellagio OpenMAX IL — preserved Debian-source import

This archive contains upstream **Bellagio 0.9.3**, an OpenMAX Integration Layer
1.1.2 implementation, and distribution patches. The project originates with
[Bellagio/OpenMAX IL](https://sourceforge.net/projects/omxil/) and the contributors
credited in [AUTHORS](AUTHORS), not with 9base.

The [23 June 2020 import](https://github.com/9base/libomxil-bellagio/commit/f7b3deb457cd64b5ccdebdee1b4d920a5093006c)
explicitly states that the source came from Debian. A subsequent
[patch-application commit](https://github.com/9base/libomxil-bellagio/commit/4ae5c71c258ed019126dc66c53d11e91cd408c14)
changes 25 files. This establishes local import/application work, not original
authorship of the library or packaged fixes. The exact Debian source-package
revision was not established.

The [upstream README](README), [COPYING](COPYING), distribution [patches](patches)
and their author headers, including Marc-André Lureau's credit, remain unchanged.
Historical upstream build guidance is retained without a claim of present
buildability. No relationship to other 9base platform collections is inferred.
